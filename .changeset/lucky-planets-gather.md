Adds `plan-with-me` — an interactive planning skill that turns a vague request into an agreed, written plan. It reads the code before it asks anything, then works through one question per turn, each with concrete options and a recommendation, until the plan is settled by either the user or its own completion test, and finally writes the plan to a single Markdown file. Its central constraint is that unknowns are resolved by evidence or handed back to the user — never filled with an assumption.
